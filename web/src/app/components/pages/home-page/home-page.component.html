О проекте

Каталог автопроизводителей и их модельных рядов

AutoMarket — учебный full-stack проект: REST API на ASP.NET Core с PostgreSQL и Angular-клиент поверх него. Производители, модели, фильтры по регионам, поиск и полный CRUD без перезагрузки страницы.
